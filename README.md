# Custom Odoo addons

Custom business modules for the local Odoo 18 Community development setup.

## Grandora modules

- `business_inventory_sales` — adds Inventory/Sales notes and product template fields for testing the customization workflow.
- `grandora_invoice_report` — Grandora browser-print invoice layout.
- `grandora_onhand_batch_dashboard` — on-hand batch cost dashboard.

## Vendored OCA modules

- `report_xlsx_helper`
